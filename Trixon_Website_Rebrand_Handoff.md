## How to Use This Document

This is a complete, page-by-page specification for rebranding trixon.cloud. Work through sections in order. Start with **Section 4** (global find-and-replace) first, then apply page-specific changes in Sections 1–3.

Each change is tagged with one of:
- `[REWRITE]` — replace the entire field with the new copy provided
- `[REMOVE]` — delete this element entirely, no replacement
- `[ADD]` — insert new element at the specified location
- `[RENAME]` — change a label, nav item, or URL slug only

> **Do not change:** images, colors, fonts, layout structure, component architecture, testimonials, contact email, or LinkedIn URL. Only copy and labels change.

## Section 0 — Strategic Direction

Read this before editing anything. This context governs every rewrite decision below.

### What Trixon Was
- A solo fractional CTO / technical co-founder service
- Served non-technical founders at pre-seed and seed stage
- Offered Build-Operate-Transfer (BOT) and TTCF engagement models
- Positioned around the "Scale-Up Gap" — prototype to production
- Emphasised code ownership, IP transfer, and team independence

### What Trixon Is Becoming
- An AI Automation Agency serving SMBs, startups, and operators
- Builds custom automation workflows, AI-integrated systems, and intelligent tools
- Core services: Workflow Automation, AI-Integrated Dashboards, Voice Bots & Calling Agents, Data Pipelines, CRM/Ops Automation
- Outcome: clients save time, eliminate repetitive manual work, and scale operations without hiring
- Delivery: fixed-scope project engagements and ongoing retainers

### New Tagline
> We build the systems that run your business while you sleep.

### New One-Liner
> Trixon builds custom AI automations, voice agents, and intelligent dashboards for businesses that are done doing things manually.

### New ICP (Ideal Customer Profile)
- SMB owners and operators with repeatable, manual workflows (sales follow-ups, lead routing, reporting, scheduling)
- Early-stage startups that need AI features built into their product or ops
- Founders and teams using fragmented tools (Notion, Airtable, Sheets, HubSpot) with no automation layer
- Businesses spending money on human effort for tasks a bot could handle (inbound calls, lead qualification, data entry)

### Service Name Master Reference — Apply Everywhere
| Old Name | New Name |
|---|---|
| Technical Audit | Automation Audit |
| TTCF — Temporary Technical Co-Founder | AI Integration Sprint |
| BOT — Build-Operate-Transfer | Full Automation Build |
